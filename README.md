# 视频下载器（Android）

手机独立运行：粘贴/分享抖音、B站、X 的视频链接或抖音图文链接，解析后排队下载，保存到系统「下载 / 视频下载器」。视频可选择画质，图文可勾选照片，按原帖顺序保存选中图片和文案。内置 yt-dlp 与 FFmpeg，不依赖电脑解析服务。

## v1.7.0

- 底部玻璃栏增加「生图」，支持与首页、下载队列点击或滑动切换。
- 接入 [基元律动模型列表](https://tokenrhythm.studio/models) 中的 `qwen-image-2.0` 和 `wan2.7-image`，每次使用文字描述生成一张图片，显示公开接口返回的当前价格和可用状态。
- 在生图页「设置」中填写个人平台 API Key。使用 Android Keystore AES-GCM 加密保存在手机内；不内置密钥，不上传密钥到 GitHub。图片 CDN 请求不携带 API Key。
- 支持生成状态、停止等待、大图预览、本机作品历史、保存至 `下载/视频下载器/生图`。两个视频下载任务可在生图期间继续。
- 网络中断或超时不自动重复提交计费请求；停止等待不能撤销服务端已提交的生成或计费。
- **接入验证边界**：公开文档目前未列出生图参数示例，当前使用 `POST https://tokenrhythm.studio/v1/images/generations` 的标准 `model / prompt / n=1` 请求，处理 `data[].url` 和 `data[].b64_json`。模型目录已在线核对；未使用用户密钥进行真实付费生图。平台若要求其他参数或异步任务协议，需要按实际调用示例调整。

## v1.6.0

交付文件：`dist/视频下载器-v1.6.0-arm64.apk`。默认同时处理 2 条下载，保留旧版队列、图片选择与 X 登录信息。

- **两路并发**：数据库事务领取任务，防止重复执行。完成、失败或取消后自动补位；下载期间新加的任务也能使用空闲位置。
- **独立控制**：每条保留进度和取消按钮；通知栏显示汇总和单条进度，支持取消此条或全部取消。取消一条不停止另一条，取消和完成状态互斥。
- **合并排队**：FFmpeg 后处理使用跨进程文件锁，音视频合并、封装修复同时最多运行一条；网络下载不持有这个锁。锁由内核管理，进程退出不会留下死锁。
- **保存安全**：并发保存同名文件时保留各自文件，不删除另一条的成品。
- 验证记录见 `docs/VERIFICATION-v1.6.0.md`。X 仍只做离线和本机素材验证，真实 X 下载由用户验收。

## v1.5.1

交付文件：`dist/视频下载器-v1.5.1-arm64.apk`。沿用原签名，保留已有队列、图片选择和 X 登录信息。

- **长视频下载恢复**：X 在所选分辨率有完整 HTTP 视频时优先使用它，否则保留原格式。网络和分片各最多重试 5 次，使用有上限的退避；失败的分片必须中止，不跳过后发布残缺文件。可恢复的 X 网络错误会重新提取一次媒体地址，同格式保留临时数据续传，不同格式使用不同临时文件避免混接。
- **息屏下载**：前台下载期间持有 CPU 唤醒锁，完成、失败或取消后释放；系统强行结束 App 或 VPN 断线仍可能中断下载。
- **错误与进度**：保留分片请求的 403、超时等详情并隐藏媒体 URL 查询参数；修正通知栏百分比。没有收到媒体数据时给出可读原因。
- 本轮没有请求或下载任何真实 X 视频；已使用本机视频测试分片恢复、拒绝请求以及格式选择，实际 X 长视频由用户验收。详见 `docs/VERIFICATION-v1.5.1.md`。

## v1.5.0 主要功能

交付文件：`dist/视频下载器-v1.5.0-arm64.apk`。包名 `com.videodl.app`，Android 10+，arm64。沿用原签名，可覆盖旧版；数据库 1→2→3→4 使用明确迁移保留任务历史。

- **图文选择下载**：图片预览网格支持逐张勾选、全选、清空和已选张数。默认不勾选；旧任务也必须先选择图片。选择存入数据库，重启仍保留；下载时只保存所选图片及文案，保留原帖序号（例如第 2、5 张保存为 002、005）。图片总数变化时要求重新选择，空选择不会启动下载；顶部批量下载跳过未选图片的图文。
- **抖音无水印视频**：将官方 `/aweme/v1/playwm/` 地址转换为同域的 `/aweme/v1/play/` 原始播放源，新解析和旧缓存均处理；显式标记为水印的 CDN 地址不采用。保留原始声音和画面，不重编码。已用含平台水印的视频核对，干净源无平台水印；作者自行嵌入画面的文字、品牌标识仍保留。
- **抖音 slides 图文修复**：支持新版短链跳转的 `/share/slides/作品编号/`，转到同作品的官方 note 分享页获取图文元数据。用户提供的作品已实测保存全部 5 张图片和文案。旧失败条目点「重试」。同时修复首次打开 App 尚未访问队列时的解析自动跳转等待问题。
- **冰蓝玻璃图标**：玻璃下载箭头与播放镂空，适配 Android 自适应裁切和 Android 13+ 单色主题。设计与原生预览见 `design/icon/`，图标验收见 `docs/VERIFICATION-v1.4.1.md`。
- **首页 / 下载队列**：底部中间的悬浮胶囊导航，支持点击和页面左右滑动。批量解析结束、重试解析结束或游客验证成功后自动切到队列；新任务在最上方。接收其他 App 分享时返回首页输入框。
- **折射玻璃导航**：参考 Apple Liquid Glass 的透镜折射、高光和悬浮层设计。Android 13+ 使用 AGSL 对真实页面内容进行实时采样、边缘弯曲、轻微放大和色散，图标及文字保持清晰；Android 12 为磨砂玻璃，Android 10/11 为透明玻璃。着色器无法创建时自动回退。适配浅色/深色与系统安全区域。
- **任务预览与单条下载**：每条解析成功的任务显示封面及独立「下载视频」或「选择要下载的图片」或「下载已选图片及文案」按钮，顶部保留批量下载。预览加载失败时展示占位文字，不影响下载；已完成图文从本机读取首图。
- **删除条目**：可删除完成记录，或清理已结束任务；只删除队列条目，保留 MediaStore 中的视频、图片和文案。
- **抖音图文**：支持普通图文分享链接（短链和 `/note/`）。按原帖顺序保存勾选的图片及 `文案.txt`，文件位于「下载/视频下载器/作品标题 [作品编号]/」。完成任务可点「查看文件」逐张打开。按图片实际格式保留 JPEG/PNG/WebP 等后缀；图文没有视频画质选择。下载前刷新图片地址，失败可重试；本次下载失败或取消会清理未完成文件，保留既有文件。
- **抖音游客方式**：独立解析官方分享页；自动取得并保留官方游客 Cookie（ttwid）。遇到平台验证时，在失败任务中点「游客验证」，完成官方页面验证后重试，无需注册账号。页面仍不提供公开视频信息时会明确失败，不承诺所有链接可用。
- **画质不虚标**：分享页的原视频尺寸可能不等于实际下载流尺寸。不能确认分辨率时显示「分享页画质」，不把它标成原视频高清尺寸。
- **解析与下载一致**：保存成功的规范地址、接口和抖音媒体元数据。下载前尝试刷新抖音地址；官方 HTTP 页暂不返回数据时可沿用 WebView 已解析的地址。过期地址需重试或重新游客验证。
- **X 登录信息**：首页「X 登录」可打开官方网页登录并保存本机会话，或导入 Netscape 格式 Cookie 文件。手机 X 客户端的登录不自动共享到下载器。解析和下载共用本机会话；可清除，不清理抖音游客 Cookie。保存状态不代表账号权限或会话有效性已验证。
- **X 接口回退**：主接口失败且符合回退条件时，尝试官方公开 syndication 接口；下载复用成功接口。私密、删除、明确 DNS/TLS 错误不盲目回退。
- **网络设置**：右上角「网络」可设置 X 的 HTTP/SOCKS5 代理。已有系统 VPN 时通常留空。手机上的 `127.0.0.1` 指手机自身；电脑代理要用电脑局域网地址，并允许手机连接该端口。
- **错误详情**：区分 DNS、TLS、超时、访问限制；失败任务可查看和复制完整详情。
- **引擎**：内置官方 yt-dlp **2026.08.19**，已核对官方 SHA256；覆盖安装会替换旧引擎，保留在线更新的更高版本。任务执行与引擎更新互斥。
- 保留混合队列、取消、所选画质、B站 `?p=N` 分P和 FFmpeg 合并功能。重试会先重新解析，保留仍可用的画质；随后点「开始下载」。

## 手机使用

1. 覆盖安装新版，允许通知。
2. 粘贴视频或抖音图文链接，点「解析链接」，完成后自动跳到下载队列。视频可选择画质，再点卡片上的「下载视频」；图文点「选择图片」，勾选后「保存选择」，再点「下载已选图片及文案」。顶部「开始下载」启动视频和已有图片选择的待下载任务。完成后图文任务点「查看文件」。
3. 抖音出现游客验证提示时，点任务中的「游客验证」。验证码由你在官方页面完成；仅登录后可见的内容不属于游客下载范围。
4. X 需要登录时，先开启 FlClash（将视频下载器纳入 VPN），在首页点「X 登录」→「打开官方登录页」，在页面完成登录后点「保存登录信息」，关闭后点失败任务的「重试」。网页登录受 WebView/平台限制时，可从已登录的浏览器导出 Netscape 格式 cookies.txt 再导入。
   登录 Cookie 不要发给他人；本应用仅提取 X 的 auth_token、ct0 和 twid，排除其他网站 Cookie。旧 twitter.com 会话映射到 yt-dlp 当前使用的 x.com 接口。登录过期或账号无权观看时仍可能失败。
5. 小米/MIUI：将本应用省电策略设为「无限制」，避免息屏清理下载服务。

支持普通视频和抖音普通静态图文链接；图文保存图片和文案，不合成视频，也不包含配乐或实况动轨。平台登录要求、账号权限和接口兼容性仍会影响解析，不承诺所有帖子可下载。抖音视频采用官方无水印播放源；不会抹除作者在原画面中嵌入的文字或标识。

## 构建

使用 JDK 17 和 Android SDK 34（可在 Android Studio 中安装）。首次构建由 Gradle Wrapper 下载 Gradle 8.7 和依赖。复制下列模板为 `local.properties`，改成自己的 SDK 路径：

```properties
sdk.dir=/你的/Android/SDK/路径
```

```bash
./gradlew :app:testDebugUnitTest :app:assembleRelease
```

本项目下载的 SDK、模拟器、Gradle 和缓存位于 `.build-env/`，上传完成后可整体删除；`.gradle/`、`.kotlin/`、`app/build/` 也可重新生成。已有 APK 保存在本机 `dist/`，不纳入源码仓库。

原交付签名单独保留在本机 `.signing/debug.keystore`，该目录不上传 GitHub。以后在本机继续发布可覆盖旧版的 APK，使用原签名：

```bash
ANDROID_USER_HOME="$PWD/.signing" ./gradlew :app:assembleRelease
```

换机器时首次构建会生成自己的 debug 签名；若要覆盖已安装旧版，需要自行安全转移原签名文件，不能上传到源码仓库。

源码：`app/src/main/java/com/videodl/app/`。Python 工具使用 `/Users/weijie/miniconda3/envs/default/bin/python`，App 内嵌的 Python 则由 Android 库提供。
