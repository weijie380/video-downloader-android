# v1.8.0 对话式生图与删除验证

日期：2026-10-04。versionCode 13，Android 10+ arm64。沿用原签名，Room 数据库仍为版本 4。

## 功能

- 生图页改为对话界面：每轮显示输入、图片预览与操作，底部保留输入框。新图片完成后滚到最新结果及操作按钮。
- 第一轮生成图片，后续发送参考图和修改要求。默认修改最新图片，也能点击历史轮次的「从此图继续」选择参考图。
- 支持新建对话、打开历史、删除单轮、从历史删除整个对话。生成、保存或删除进行中锁定历史变更，避免删掉正在使用的图片。
- 图片保存在私有持久目录。删除先原子更新索引，再删除所选私有文件；已通过 MediaStore 保存到系统下载目录的副本保留。
- 旧版索引缺少 conversationId 时，以原图片 ID 作为独立会话 ID；不改写旧图，不要求重新生成。

## 编辑接口与验证边界

- [公开模型目录](https://tokenrhythm.studio/models)的 `qwen-image-2.0`、`wan2.7-image` 均标记支持图片编辑；本轮核对 `GET /api/models` 返回的 supportsImageEditing 与 online 状态。
- 第一轮沿用 JSON `POST /v1/images/generations`。后续使用 `POST /v1/images/edits`，multipart 字段为 `model / prompt / n=1 / image`，上传所选轮次的实际图片文件。支持 PNG、JPEG、WebP，参考图上限 32 MB。
- 编辑失败保留输入和原结果，不自动退回文生图，不自动重复提交计费请求。密钥保护、取消等待与 CDN 请求不携带鉴权头的规则沿用 v1.7.0。
- [平台公开接入文档](https://tokenrhythm.studio/docs/api-integration)没有图片编辑参数示例。无鉴权 GET 编辑路由返回 401，仅说明路由存在，不能证明鉴权后的 multipart 参数或真实编辑成功。
- 未使用用户 API Key，未进行付费生图或编辑。实际平台兼容性与修改效果仍需用户配置账号后验收。
- 未请求任何真实 X 帖子、预览、视频清单或媒体。

## 最终 APK 界面验证

- 在自建临时模拟器先安装 v1.7.0，写入仅含旧版五个字段的合成图片记录，再覆盖安装 v1.8.0。旧图片和文案正常出现，并成为可继续修改的独立对话。
- 新建对话后显示初始提示，打开历史可回到两轮测试对话；默认参考第 2 轮。选择第 1 轮后，输入区明确显示「修改第 1 轮图片」。
- 保存第 2 轮出现「已保存」，系统下载目录存在图片。删除该轮后，私有索引和图片文件均移除；第 1 轮及另一个旧会话保留，导出的第 2 轮副本保留。
- 从历史删除剩余测试对话，再强制停止并重启应用，已删除会话不再出现；另一个旧会话及导出副本保留。
